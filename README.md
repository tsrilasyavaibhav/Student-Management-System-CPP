# Student-Management-System-CPP

## Description
A console-based Student Management System developed in C++ using file handling.

## Features
- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Persistent Storage using Files

## Technologies Used
- C++
- File Handling
- Object-Oriented Programming

## How to Run

Compile:
g++ main.cpp -o sms

Run:
./sms
